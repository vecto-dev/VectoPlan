# VectoPlan

**A personal productivity and planning web app**

VectoPlan is a personal project designed to bring productivity and planning tools together in one interface.

## About the Project

I created VectoPlan as a beginner exploring web development and AI-assisted development. The project is part of my journey to learn how ideas can be transformed into interactive web applications.

## Current Project

- Responsive interface for desktop and mobile layouts
- Multiple visual themes and UI styles
- Animated transitions and interactive elements
- Task-related planning interface
- Chatbot-style interface

*These are interface and code-level features; individual functions should be tested before being described as fully working.*

## Technologies

- HTML
- CSS
- JavaScript
- Tailwind CSS via CDN
- Font Awesome

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Allow an internet connection for the external fonts and libraries used by the page.
